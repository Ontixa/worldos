# Governance

WorldOS is stewarded by its maintainers under a lightweight model that
will formalize as the community grows.

## Roles

- **Maintainers** — merge rights; own releases, roadmap, and the
  architectural invariants in `CONTRIBUTING.md`.
- **Contributors** — anyone filing issues/PRs.

## Decisions

- Day-to-day: maintainer review on PRs; two eyes for anything touching
  the kernel, command layer, or permissions.
- Architectural changes: an ADR in `docs/adr/` before implementation.
- Disagreements resolve toward the project thesis: one governed world,
  no bypasses, depth before breadth.

## ADR process

Copy an existing ADR, number it sequentially, mark status
`proposed`/`accepted`/`superseded`. PRs implementing an accepted ADR
reference it.
